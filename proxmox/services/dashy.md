# Dashy

[Service index](README.md) · [Proxmox server](../README.md)

## Purpose

Dashy is a lil self-hosted dashboard for organizing links and information about services, that can help u find things easier also it is higly customisable. See the [official documentation](https://dashy.to/docs/).

## In My Homelab

Dashy runs in a container on my Proxmox server as part of the dashboard setup.

The tablet's [Home Assistant dashboard](../../raspberry-pi/home-assistant/README.md) has its own page covering home controls and server monitoring.

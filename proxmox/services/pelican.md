# Pelican Panel and Wings

[Service index](README.md) · [Proxmox server](../README.md)

## Purpose

Pelican provides game server management. The Panel is its web interface, while Wings manages the game server containers on behalf of the Panel. See the [official documentation](https://pelican.dev/docs/).

## In My Homelab

Pelican is the game server management part of my setup. Panel and Wings run in separate Proxmox containers.

The Panel provides the management interface, while Wings handles the game server containers.

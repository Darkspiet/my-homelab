# Nginx Proxy Manager

[Service index](README.md) · [Proxmox server](../README.md)

## Purpose

Nginx Proxy Manager provides a web interface for managing reverse proxies and certificates. See the [official project site](https://nginxproxymanager.com/).

## In My Homelab

Nginx Proxy Manager runs in a Proxmox container and forms part of the infrastructure around my self-hosted services.
